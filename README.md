# UnityLearning
A repo where I collect every challenges and prototypes I have built based on the Official Unity Course "Create With Code"!

These packages are made by me, notoastedtoast, and feel free to use it and develop it further; it can be used for your personal project, game, simulation or other stuffs.  The Game Objects, SFX and Music, they are owned by Synty Studios and must pay for commercial use, other than that you can make anything with it, the only limit is your creativity and imagination!
To use the packages, go to Assets -> Import Packages -> Custom Package and select your desired package after download. Then, pull the scene into the Hierarchy and delete the SampleScene. After that, start explore and create!
